# Logboat

Logboat collects logs from your hosts and sends them to one place, so your team
can search and read them together.

## How it works

Each host runs a collector agent. The agent ships the logs to Logboat, and the
transformation engine processes them before they are stored.

## Getting started

1. Install the agent on each host.
2. Start the agent. It finds the log sources on the host by itself, so you do
   not have to configure them.
3. Open the dashboard to read your logs.

## Features

- Integrations with more than 50 tools
- Security controls for enterprise deployments
- Scaling to petabytes
