# Logboat

Logboat collects logs from your hosts and keeps them in one place.

## How it works

Logboat uses a pipeline. The collector gathers logs on each host. The
transformation engine then processes them.

## Install

1. Install the agent on each host.
2. Start the agent.

The agent finds the log sources on the host and ships them to Logboat. You do
not need to configure it.

## Dashboard

Logboat has a dashboard that shows your log data. The platform needs no
configuration, and it processes logs quickly.

## Features

- Connects to more than 50 tools.
- Has security controls for enterprise use.
- Scales to petabytes.
