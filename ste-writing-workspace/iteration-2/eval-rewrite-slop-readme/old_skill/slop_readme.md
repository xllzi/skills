# Logboat

Logboat is a cutting-edge, robust log aggregation platform that seamlessly
empowers teams to leverage their log data like never before.

It's important to note that Logboat utilizes a revolutionary next-generation
pipeline architecture. The logs are ingested by the collector, and then they
are processed by the powerful transformation engine. Our world-class solution
ensures that your data is handled effortlessly — facilitating unparalleled
observability across your entire stack.

In order to get started, simply perform an installation of the agent on each
host. The agent will automatically commence discovering your log sources
prior to shipping them. Additionally, the platform provides a comprehensive
dashboard. Furthermore, it doesn't require any configuration. Moreover, it's
blazing fast.

## Features

- Seamless integration with 50+ tools
- Robust, enterprise-grade security
- Effortless scaling to petabytes
