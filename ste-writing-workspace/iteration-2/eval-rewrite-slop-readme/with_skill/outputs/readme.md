# Logboat

Logboat is a log aggregation platform. It helps teams use their log data.

The platform uses a pipeline architecture. The collector ingests the logs. The
transformation engine then processes them. This gives you observability across
your whole stack.

To start, install the agent on each host. The agent discovers your log sources,
then ships them. The platform also includes a dashboard. You do not need to
configure the agent. It is fast.

## Features

- Integration with 50+ tools
- Security for enterprise deployments
- Scaling to petabytes
